# Triage labels

Default five-label vocabulary, applied as beads labels:

| Label | Meaning |
|---|---|
| `needs-triage` | New, unreviewed |
| `needs-info` | Blocked on a question |
| `ready-for-agent` | Specified and claimable (the state `to-spec` applies) |
| `ready-for-human` | Needs a human decision |
| `wontfix` | Explicitly out of scope |
